# Sitemap & 페이지별 기획

## 공통 UI

### Header

- 로고 아이콘 - 서비스 이름 ## `/` 메인페이지
- 정산방 생성하기 버튼 - `/room/create` 로 이동 - 서비스 설명 - 서비스 공유하기 링크 버튼 - 링크 URL 복사 버튼 ## `/room/create` 정산방 생성
- 정산방 정보 입력 - 정상방 타이틀 → Text Input - 총예산 → Number Input - 여행 멤버 이름 → Text Input - 새로운 멤버 추가,
  기존멤버 이름 수정,
  멤버 삭제 UI - 1 인당 예산 → 총예산,
  여행 멤버 이름 입력되면 1 인당 예산 자동으로 계산해서 보여주기 - 썸네일 이미지(선택) → File Input - 확인 버튼 - `/room/confirm` 로 이동 ## `/room/confirm` 정산방 생성 정보 확인
- 입력한 정산방 정보 최종 확인 - 생성 버튼 - `/room/done` 로 이동 ## `/room/done` 정산방 생성 완료
- 정산방 공유하기 링크 복사 버튼 - 정산방으로 이동 버튼 ## `/room/{id}` 정산방 메인(대시보드)
- 공통헤더 UI 변경: `/room/{id}` 으로 시작하는 페이지 전체 유지 - 좌측 - 로고아이콘 → 클릭: 서비스 메인 페이지 - 서비스 이름 대신 정산방 타이틀 텍스트 표시 → 클릭: 정산방 메인으로 이동 - 우측 - 햄버거메뉴 아이콘 → 클릭: 우측에서 메뉴 Drawer 표시 - 정산방 섬네일 표시 및 링크 복사 버튼 - 정산 완료하기 버튼 → 클릭: 확인모달 띄운후 확인시 `/room/{id}/result` 이동 - 메뉴: 정산방 수정 → 클릭: `/room/{id}/edit` 이동 - 메뉴: 결제 내역 리스트 → `/room/{id}/receipt` 이동 - 우측하단 + 버튼 - `/room/{id}/receipt/create` 이동 - 결제 총액 - 총액 표시 - 예산총액 표시 - 예산 대비 결제금액 % 프로그레스바 - 5 단계 단계별로 다른 색상 표시 - 25 % 미만 - 50 % 미만 - 75 % 미만 - 100 % 미만 - 100 % 초과 - 최근 결제 내역 - 최신순으로 3 건 표시 - 표시정보 - 결제처 - 금액 - 결제자 - 클릭: `/room/{id}/receipt/{id}` 이동 ## `/room/{id}/edit` 정산방 정보 수정
- 정산방 정보 입력(기존 값 디폴트로 입력) - 정상방 타이틀 → Text Input - 예산 → Number Input - 여행 멤버 이름 → Text Input - 새로운 멤버 추가,
  기존멤버 이름 수정,
  멤버 삭제 UI - 1 인당 예산 → 총예산,
  여행 멤버 이름 입력되면 1 인당 예산 자동으로 계산해서 보여주기 - 썸네일 이미지(선택) → File Input - 수정하기 버튼 - `/room/{id}` 이동 ## `/room/{id}/receipt/create` 결제 내역 생성
- 정보입력 - 결제처 → Text Input - 금액 → Number Input - 결제자 → Drop Down - 멤버중 선택 - 결제일시 → DateTime Picker - 설명(선택) → Text Area - 증빙이미지(선택) → File Input - 생성 버튼 - `/room/{id}` 이동 ## `/room/{id}/receipt` 결제 내역 리스트
- 검색창 - 결제처,
  금액으로 검색 - 결제자 멤버이름을 기준으로 필터링 - 디폴트는 전체보기 - 리스트 표시 - 표시정보 - 결제처 - 금액 - 결제자 - 20 건식 조회 - 최신순 정렬 - 무한스크롤 - 클릭: `/room/{id}/receipt/{id}` 이동 ## `/room/{id}/receipt/{id}` 결제 내역 상세
- 표시정보 - 결제처 - 금액 - 결제자 - 결제일시 - 설명(선택) - 증빙이미지(선택) - 수정하기 버튼 - `/room/{id}/receipt/{id}/edit` 이동 - 삭제하기 버튼 - 확인 모달 띄우고 확인시 삭제 - 삭제후 `/room/{id}` 이동 ## `/room/{id}/receipt/{id}/edit` 결제 내역 수정
- 정보입력(기존 정보 디폴트값으로 입력된 상태) - 결제처 → Text Input - 금액 → Number Input - 결제자 → Drop Down - 멤버중 선택 - 결제일시 → DateTime Picker - 설명(선택) → Text Area - 증빙이미지(선택) → File Input - 확인버튼 - 수정후 `/room/{id}/receipt/{id}` 이동 ## `/room/{id}/result` 정산 결과 확인
- 정산방 이름 - 정산 기간(정산방 생성시점 ~ 완료시점) - 결제 총액 - 예산(작게) - 예산 대비 초과율 / 미달률 % - 정산 송금 지침 - 실제 1 인당 비용 = 결제총액 / 멤버수 - 누가 얼마를 총무에게 보내거나 받아야하는지 표시 - 예시
  ) - 시원 + 30,
  000 원 총무에게 받으세요 - 동헌 -30,
  000 원 총무에게 보내주세요 - 레거시(혹시 필요해지면 살리기) - 일자별 결제액 바 차트 - 일자가 많으면 좌우 스크롤 - 삼성헬스 걸음수 차트와 유사하게 - 도넛차트 - 결제자 태그별 비중 표시(좌측) - 범례 태그별 이름(우측)
